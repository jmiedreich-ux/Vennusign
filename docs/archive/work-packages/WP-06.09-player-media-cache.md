## Goal

Keep the last valid menu visible through temporary content or media outages while preserving the normal online boot path.

## Scope

- Store successful display content in a versioned, per-screen browser cache.
- Fall back only for transient API/network failures and only to fresh content for the requested screen.
- Invalidate stale, corrupt, cross-screen, and older-version content.
- Add a versioned image service-worker cache with old-version cleanup and network recovery.
- Recover online content, heartbeat, and real-time behavior without reloading the player.
- Add focused non-integration display tests.

## Acceptance Criteria

1. Successful online loads replace the cached content for that screen.
2. Temporary API failure displays a valid cached board with an offline status.
3. A 404 never revives a removed screen from cache.
4. Cache version, screen identity, age, and JSON validity are enforced.
5. Images refresh from the network and fall back to the current versioned cache while offline.
6. Returning online restores live content, heartbeat, and real-time updates.
7. GitHub Actions passes the display build/tests and required non-integration checks.
8. Integration-type tests remain skipped.

## Boundaries

No installable PWA shell, background sync, scheduling, POS integration, or Phase 07 layout/theme work.
