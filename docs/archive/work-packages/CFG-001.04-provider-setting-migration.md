## Scope

- Register exact configuration keys consumed by Google, Apple, email delivery, Stripe, Square, Toast, Clover, and Super Admin options.
- Mark credentials write-only, encrypted, restart-required, and excluded from standard exports.
- Retain safe endpoint/default definitions for non-secret values.
- Remove committed reusable Super Admin and Stripe API credentials from appsettings.
- Preserve a validation-safe non-secret Stripe webhook placeholder until configured.
- Document local and hosted bootstrap, encryption, precedence, restart, and management behavior.

## Compatibility

Existing options consumers continue using normal .NET binding. When the database provider is enabled, database values override appsettings; environment variables and command-line values remain emergency overrides.
