## Objective

Prove the Phase 02 milestone end to end before Phase 03 begins.

## In Scope

- Run the complete automated validation suite.
- Validate with separate admin/API and display client contexts.
- Create a venue and screen.
- Create and claim a pairing code.
- Load display content.
- Confirm SignalR group connection and a real-time update.

- Missing heartbeats produce offline status.
