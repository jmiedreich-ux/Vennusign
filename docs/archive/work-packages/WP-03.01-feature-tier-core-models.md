# WP-03.01 — Feature and Tier Core Models

## Objective

Establish the persistent feature, subscription tier, tier entitlement, and venue subscription foundation for Phase 03.

## Implemented

- Added `Feature`, `SubscriptionTier`, `TierFeature`, and `VenueSubscription` core models.
- Added DbUp migration `004_create_feature_tier_core.sql`.
- Added constraints and indexes for unique feature keys, tier slugs, Stripe subscription IDs, status values, pricing, and screen limits.
- Seeded the roadmap tiers: Starter, Restaurant Starter, Pro, and Business.
- Seeded the initial feature catalog and tier-feature mappings.
- Added feature, subscription tier, and venue subscription repositories.
- Registered the repositories through `AddVennuData()`.
- Added repository tests covering feature lookup, tier mappings, and venue subscription insert/update behavior.

## Scope Boundaries

- No Stripe API integration.
- No feature resolution service.
- No venue feature overrides.
- No API feature enforcement.
- No customer-facing administration UI.

## Validation

- Repository unit tests.
- Migration execution and seed validation through the configured integration database when available.
- Full solution build and `./scripts/validate.ps1 -SkipDisplay` through PR CI.
