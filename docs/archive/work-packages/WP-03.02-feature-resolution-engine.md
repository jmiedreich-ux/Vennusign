# WP-03.02 — Feature Resolution Engine

## Objective

Provide one authoritative service for resolving a venue's effective feature access before customer-facing administration and billing workflows are built.

## Delivered

- `VenueFeatureOverride` model and DbUp migration.
- Override repository with required reasons and expiry support.
- `IFeatureResolutionService` with:
  - `HasFeatureAsync`
  - `GetFeatureAsync`
  - `GetFeatureSetAsync`
  - venue cache invalidation
- Resolution order:
  1. inactive master feature remains disabled
  2. active or trialing subscription supplies tier features and limits
  3. unexpired venue override wins over the tier
- 60-second sliding `IMemoryCache` entry per venue.
- Dependency injection registration.
- Unit coverage for override precedence, master switches, trial access, and limit values.

## Scope Boundary

This package does not implement usage consumption, Stripe synchronization, API authorization filters, upgrade prompts, or customer-facing UI.

## Validation

- Build the solution.
- Run `Vennu.DataAccess.Tests`.
- Run migrations against the configured integration database.
- Run `./scripts/validate.ps1 -SkipDisplay`.
