# WP-10.05 — Android Kiosk and Operator Escape

## Status

Complete

## Goal

Add opt-in Android TV kiosk behavior, screen-awake handling, and a protected local operator escape.

## Acceptance Criteria

- Kiosk is disabled by default and changes only through the trusted `/pair?vennuKiosk=1|0` contract.
- Enabled kiosk keeps the screen awake and applies immersive TV UI.
- Device-owner lock task is used when permitted; otherwise screen pinning is requested with a safe immersive fallback.
- Long-press Back requires the Android device credential before kiosk is disabled and Home is opened.
- Devices without a secure credential refuse local exit and explain the prerequisite.
- No operator PIN, signing secret, or device-owner credential is committed.
- Focused non-integration tests cover opt-in, lock-task branches, awake state, protected exit, and fallback.

## Boundaries

No device-owner provisioning, distribution variants, signing, store submission, or player logic fork.

## Validation

GitHub Actions is authoritative. Integration-type and physical-device tests are intentionally skipped.
