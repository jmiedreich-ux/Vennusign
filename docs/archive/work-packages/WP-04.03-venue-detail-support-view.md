# WP-04.03 — Venue Detail & Support View

## Status

Complete pending authoritative CI, review, and merge.

## Goal

Give internal support staff a protected, read-only view of one venue's operational and entitlement context.

## Scope

- Compose the venue profile, subscription, tier, screens, effective features, and active overrides.
- Return 404 for unknown venues.
- Open the support view from the venue directory.
- Provide loading, error, not-found, empty, and responsive UI states.
- Add focused non-integration unit tests.

## Acceptance Criteria

1. The API returns existing support context without duplicating persistence logic.
2. Unknown venue IDs return 404 without loading related records.
3. Screens and features use deterministic ordering.
4. The admin UI navigates from the directory and back.
5. Required non-integration checks pass; integration-type tests are skipped.

## Boundaries

Tier switching, override mutation, audit events, and revenue calculations are deferred.
