# WP-10.04 — Android Boot and Lifecycle Recovery

## Status

Complete

## Goal

Add opt-in boot launch and bounded lifecycle/network recovery to the Android-family shell.

## Acceptance Criteria

- Boot launch is disabled by default and changes only through the trusted `/pair?vennuBoot=1|0` contract.
- The boot receiver starts the TV activity only after explicit opt-in.
- Foreground return refreshes stale shell state while short interruptions resume in place.
- Network availability retries only an error state.
- Automatic recovery is rate-limited and capped until a successful page commit.
- Manual retry resets the automatic-recovery budget.
- Focused non-integration tests cover permissions, boot opt-in, lifecycle, network, and reload bounds.

## Boundaries

No kiosk/device-owner behavior, operator exit, screen-awake policy, distribution variants, signing, store credentials, or player logic fork.

## Validation

GitHub Actions is authoritative. Integration-type and physical-device tests are intentionally skipped.
