MAPPING NOTE — Canonical vNext ownership (added 2026-08-30)
This endpoint inventory is preserved in its original order and wording.
Every route group below is annotated as:
  MAP → primary Surface → Family → Area
  INTERACTION → another owner involved without transferring primary ownership
  REVIEW → a boundary issue that must remain visible until explicitly decided

The canonical four-surface architecture is not altered by this inventory.

VENUE API vNEXT — projected surface (2026-08-30)
Model: Collection (typed entries) x Theme (zones/repeaters/fields) = Presentation -> render -> Wall Planner (deal across the group) -> Package -> Screens, flipping on one clock
