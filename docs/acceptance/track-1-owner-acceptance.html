How this workbook works

  • Work top to bottom. Case 1 starts the environment; every case after it assumes that environment is still running.
  • Tick each step as you do it. The checkboxes are only your place-marker — they save with the record but never decide an outcome.
  • Each case signs you in itself. Where a case needs a particular role, its first step is a sign-in link that switches to that role in a new tab. You never need to sign out first, and you never type a token.
  • Record Pass, Fail or Needs Adjustment for every case. Anything other than Pass needs a note before a closure decision unlocks.

Progress saves in this browser as you type. Use Export JSON record to hand the finished record back. The sign-in links assume the Back Office is on https://localhost:5174; the token travels in the URL fragment, which browsers never transmit, and is cleared from the address bar before the page renders.
