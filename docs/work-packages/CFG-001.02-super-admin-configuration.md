## UX Guidance and Gap Analysis

The UX advisor returned no direct recommendation. Pattern search identified Data Table, Form Validation, and Progress Indicator guidance. The implementation uses a responsive settings list rather than a wide table so descriptions, typed values, and actions remain legible.

- Goal: select an environment/application, inspect registered settings, save values, and replace or clear secrets.
- Hierarchy: environment and application filters precede the setting list; each setting keeps description, type, restart status, value, and actions together.
- States: loading, empty, validation/API error, save success, stale-write conflict, secret configured/not configured, and restart-required feedback.
- Safety: secrets are write-only; clearing requires confirmation; required settings cannot be cleared; stale writes return conflict.
- Accessibility: explicit labels, text statuses, `role=status`, `role=alert`, keyboard-native controls, and responsive single-column cards.
- Authorization: read, edit, secrets, import, and admin permissions are explicit Super Admin claims. Secret writes require both edit and secrets permission.
- Deferred: import/export is CFG-001.03 and is not exposed by this page yet.

## Scope

- Configuration management repository/service with typed validation and optimistic concurrency.
- Immutable revision payloads and audit fingerprints without plaintext secret audit data.
- Super Admin configuration permission policies.
- Authenticated configuration API.
- Responsive configuration management page and focused tests.
