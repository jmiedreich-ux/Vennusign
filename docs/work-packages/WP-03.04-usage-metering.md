# WP-03.04 — Usage Metering

## Status

Complete pending pull-request validation, ChatGPT review, and merge.

## Objective

Provide authoritative monthly consumption tracking for metered features without allowing concurrent requests to exceed a tier limit.

## Implemented

- Added `FeatureUsages`, keyed by venue, feature, and UTC month.
- Added an atomic SQL `MERGE ... WITH (HOLDLOCK)` consumption path.
- Added `IUsageMeteringService` for current usage and capacity consumption.
- Preserved unlimited enabled features when no numeric tier limit is configured.
- Rejected disabled features, invalid limits, non-positive consumption, and exhausted capacity.
- Registered the repository and service through dependency injection.
- Added focused unit coverage.
- Applied the owner's standing instruction to skip integration-type tests for every AWP.
