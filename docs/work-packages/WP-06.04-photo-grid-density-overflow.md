## Goal

Deliver persisted 2x2, 3x2, 4x2, and 3x3 Photo Grid densities with deterministic video-wall slicing and bounded overflow.

## Scope

- Persist a validated Photo Grid density on each screen with a safe 3x2 default.
- Let screen management select any supported density.
- Derive each screen's item offset from the stable video-wall order and preceding screen capacities.
- Return only the current screen's bounded section slice and report overflow after the complete wall capacity.
- Render density-specific grid columns and a final-screen overflow notice.
- Add focused API, service, frontend, and migration inventory tests.

## Acceptance Criteria

1. Supported densities map to capacities 4, 6, 8, and 9.
2. Unknown density values are rejected before persistence.
3. Screen slices are stable, non-overlapping, and preserve section/item order.
4. Mixed-density video walls derive offsets from preceding capacities.
5. Only the final wall screen reports items beyond total wall capacity.
6. Required GitHub Actions checks pass.
7. Integration-type tests remain skipped.

## Boundaries

No scheduling, POS behavior, advanced themes, Classic Diner work, or external integration.
