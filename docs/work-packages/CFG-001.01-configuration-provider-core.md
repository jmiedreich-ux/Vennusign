# CFG-001.01 — Configuration Provider Core

## Status

In Progress

## Execution Mode

Collaborative

## Parent and Issue

- Program: #374
- Issue: #375

## Decisions

- Fixed environments: Development, Test, Staging, Production.
- Existing Vennu database with environment and application scope.
- Registered definitions only.
- Environment and command-line configuration override database values.
- Secret values use AES-256-GCM envelope protection. Hosted environments wrap per-value data keys with Azure Key Vault; local development may use a Base64 environment key.
- Secret defaults are prohibited and plaintext is not stored in values, revisions, or audit records.
- Runtime reload retains the last successful snapshot on transient failures.

## Bootstrap Variables

- `VENU_CONFIGURATION_ENVIRONMENT`
- `VENU_CONFIGURATION_CONNECTION_STRING` or `ConnectionStrings__VennuDatabase`
- `VENU_CONFIGURATION_KEY_PROVIDER`: `AzureKeyVault` or `Environment`
- `VENU_CONFIGURATION_KEY_ID` for Azure Key Vault
- `VENU_CONFIGURATION_LOCAL_KEY` for local development

## Scope

- DbUp schema for definitions, values, immutable revision fingerprints, and audit records.
- Idempotent provider-setting definitions.
- Database-backed .NET configuration provider and reload token support.
- Environment-key and Azure Key Vault envelope secret protection.
- API bootstrap before options binding.
- Focused cryptographic and migration-inventory tests.
