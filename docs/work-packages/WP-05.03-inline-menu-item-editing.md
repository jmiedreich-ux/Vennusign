# WP-05.03 — Inline Menu Item Editing and Sync

## Status

Complete pending GitHub Actions, review, and merge.

- Branch: `wp/05.03-inline-menu-item-sync`
- Issue: #62

## Goal

Add bounded inline editing for menu item text and prices with the existing venue notification abstraction.

## Scope

- Extend venue menu reads with deterministic item groups.
- Create items at the end of an owned venue menu section.
- Edit item name, description, base price, and optional happy-hour price inline.
- Publish one venue content-update notification after each successful write.
- Add responsive admin controls and focused non-integration tests.

## Acceptance Criteria

1. Every mutation validates venue, menu, section, and item ownership.
2. Names are trimmed, nonblank, and limited to 160 characters; descriptions are limited to 1000 characters.
3. Prices are rounded to two decimal places and remain between 0 and 999999.99.
4. New items append deterministically to their section.
5. Successful writes publish through `IScreenUpdateNotifier`.
6. Required GitHub Actions checks pass on the reviewed head.
7. Integration-type tests remain skipped.

## Boundaries

No availability, quantity, dietary/allergen tags, bestseller state, tier prompts, image upload, translation automation, display rendering, or screen targeting.

## Dependencies

- WP-05.02 — Menu Editor Read Model and Section Management
- Existing `IScreenUpdateNotifier` abstraction
