## Status

## Scope

- Provider initial/reload health telemetry without connection strings, values, or secret details.
- Last-successful snapshot retention during transient reload failure.
- Super Admin health status and secret replacement-age reminders.
- Secret-safe immutable revision metadata.
- Concurrency-protected rollback that creates a new revision and audit event.
- Operational recovery documentation and program completion reconciliation.

## UX and Safety

- Health uses explicit Healthy, Attention required, and Disabled text states.
- Secret values and revision payloads are never returned.
- Rollback requires explicit confirmation and explains that it creates a new audited revision.
- Stale rollback returns conflict without changing the current value.
- Rotation reminders use last replacement date and registered reminder days.
