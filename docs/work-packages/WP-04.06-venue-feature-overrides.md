# WP-04.06 — Venue Feature Overrides

## Status

Complete pending authoritative CI, review, and merge.

## Goal

Allow authorized Super Admin support operators to add, replace, and remove venue-specific feature unlocks or blocks.

## Scope

- Add protected venue override mutation endpoints.
- Validate the venue, active feature, required reason, reason length, and optional future expiry.
- Persist one override per venue-feature pair.
- Invalidate effective-feature cache immediately after successful mutation.
- Add responsive override controls to the venue support view and refresh effective access.
- Add focused non-integration unit tests.

## Acceptance Criteria

1. Unknown venues and features return not found without mutation.
2. Blank or oversized reasons and non-future expiries are rejected.
3. Unlock/block upserts and removal invalidate the venue cache after persistence.
4. The admin UI can add, replace, and remove overrides and refreshes effective access.
5. Required restore, Release build, admin/display production builds, and unit tests pass.
6. Integration-type tests are skipped under the standing repository-owner exception.

## Boundaries

Tier switching, Stripe synchronization, feature creation, bulk overrides, and revenue dashboard behavior are excluded.
