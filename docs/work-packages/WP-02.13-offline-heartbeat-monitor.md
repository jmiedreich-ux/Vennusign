# WP-02.13 — Offline Heartbeat Monitor

## Objective

Mark previously online screens offline when their heartbeat becomes stale.

## In Scope

- Add repository support to retrieve stale online screens or perform an equivalent verified update.
- Add a hosted background service.
- Use a 90-second stale threshold.
- Update screen status to `Offline` without changing unrelated screen data.
- Make the check interval configurable with a safe default.
- Add repository and service tests.

## Out of Scope

- Display heartbeat scheduling
- Phase 03 subscription behavior
- New screen status values

## Acceptance Criteria

- Screens with recent heartbeats remain online.
- Screens older than the threshold become offline.
- The service handles an empty result set and cancellation cleanly.
- Tests cover threshold boundaries and repeated execution.

## Required Validation

- Repository and hosted-service tests
- Integration tests against the configured test database when available
- `./scripts/validate.ps1 -SkipDisplay`

## Dependencies

Existing heartbeat persistence behavior.
