## Goal

Add popular, sold-out, dietary/allergen, limited-quantity, and happy-hour price presentation to Photo Grid using existing menu data.

## Scope

- Extend the display item contract with existing availability, quantity, tags, popular, and happy-hour fields.
- Parse stored comma-separated tags into a stable distinct display collection.
- Render popular and sold-out overlays, badges, limited quantity, and alternate happy-hour pricing.
- Add focused API and frontend non-integration tests.

## Acceptance Criteria

1. No new persistence or external integration is introduced.
2. Unavailable or zero-quantity items show a sold-out state.
3. Popular, tag, and limited-quantity states render from payload values.
4. Happy-hour alternate price renders only when `isHappyHour` is true.
5. Required GitHub Actions checks pass.
6. Integration-type tests remain skipped.

## Boundaries

No scheduling evaluation, POS synchronization, density selection, multi-screen slicing, or theme persistence.
