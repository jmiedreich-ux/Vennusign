# CFG-001.03 — Configuration Import and Export

## Status

In Progress

## Execution Mode

Collaborative

## Parent and Issue

- Program: #374
- Issue: #379

## Scope

- Versioned JSON manifests containing registered non-secret definitions and configured values.
- Standard exports exclude all secret definitions and values.
- Dry-run preview classifies new, conflicting, unchanged, valueless, and invalid entries.
- Unknown or secret entries cannot apply.
- Operators explicitly select reviewed changes and confirm application.
- Apply uses one SQL transaction, optimistic preview versions, immutable revisions, audit rows, and one import operation ID.

## UX and Safety

- Export and visible keyboard-accessible JSON file selection sit beside environment filters.
- Preview explains that secrets are excluded and disables invalid/unchanged rows.
- New values are selected by default; conflicts require explicit operator selection.
- Apply requires confirmation and reports stale previews without partial application.
- Import cancellation leaves configuration unchanged.
