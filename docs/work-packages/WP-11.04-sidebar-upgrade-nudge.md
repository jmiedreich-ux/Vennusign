# WP-11.04 — Sidebar Upgrade Nudge

## Status

Review

## Goal

Add one quiet, rotating upgrade suggestion to the venue sidebar without competing with another active prompt.

## Acceptance Criteria

- Eligible locked features rotate in deterministic catalog order every seven seconds.
- Progress dots identify and select the current suggestion.
- Dismissal applies to the current feature for the browser session.
- Reduced-motion users do not receive automatic rotation.
- The active venue screen renders either the sidebar nudge or its inline hint, never both.
- Existing workflows and authoritative entitlements remain unchanged.
- Focused non-integration tests cover ordering, rotation, dismissal, accessibility, and placement.

## Boundaries

No modal, Checkout, Billing Portal, Stripe call, pricing presentation, or entitlement mutation.

## Validation

GitHub Actions is authoritative. Integration-type and external Stripe tests are intentionally skipped.
