## Goal

Provide the validated, venue-scoped advanced theme foundation used by all Phase 07 Pro layouts without changing Phase 06 basic-theme defaults.

## Scope

- Migration 018 for preset, neon colors, section colors, glow intensity, and approved fonts.
- Five deterministic roadmap presets.
- Protected advanced update and preset-application operations.
- Preserve basic theme values during advanced updates and advanced values during basic updates.
- Focused service, contract, and migration inventory tests.

## Acceptance Criteria

1. One to four section colors and 0.20–2.00 glow intensity are enforced.
2. Title/item fonts are limited to the approved roadmap sets.
3. Bar Classic, Violet Lounge, Hot Summer, Ocean Dive, and Rose Gold are deterministic.
4. Basic theme behavior remains backward compatible.
5. GitHub Actions passes required non-integration checks.
6. Integration-type tests remain skipped.

## Boundaries

No admin full-theme controls, Neon Chalkboard rendering, font asset loading, scheduling, POS, or other later-phase behavior.
