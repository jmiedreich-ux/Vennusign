# WP-03.03 — Subscription Management

## Status

Blocked pending restoration of the Azure SQL CI credential.

## Objective

Provide one authoritative service for managing venue subscription trials, tier changes, lifecycle status transitions, expiration, and feature-cache invalidation.

## Implemented

- Added a fixed 14-day trial lifecycle without requiring Stripe.
- Added tier changes that preserve the existing lifecycle status.
- Restricted statuses to `trialing`, `active`, `past_due`, and `canceled`.
- Added deterministic elapsed-trial expiration through `TimeProvider`.
- Invalidated feature-resolution cache after every persisted subscription change.
- Added focused unit coverage for trial creation, tier changes, status validation, and expiration.
- Repaired pre-existing restore, package-version, display declaration, and migration-discovery CI failures uncovered while validating this package.

## Scope Boundary

This package does not add Stripe SDK integration, webhook processing, usage metering, API authorization filters, billing UX, or customer-facing UI.
