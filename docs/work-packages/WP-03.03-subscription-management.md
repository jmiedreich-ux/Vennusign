# WP-03.03 — Subscription Management

## Status

In Progress

## Objective

Provide one authoritative service for managing venue subscription trials, tier changes, lifecycle status transitions, expiration, and feature-cache invalidation.

## Acceptance Criteria

- Start a 14-day trial without Stripe.
- Change an existing venue's tier without silently changing lifecycle status.
- Accept only `trialing`, `active`, `past_due`, and `canceled` statuses.
- Expire elapsed trials deterministically through `TimeProvider`.
- Invalidate the feature-resolution cache after every persisted subscription change.
- Add focused unit coverage for lifecycle behavior and validation.

## Scope Boundary

This package does not add Stripe SDK integration, webhook processing, usage metering, API authorization filters, billing UX, or customer-facing UI.

## Validation

- Build the solution.
- Run `Vennu.DataAccess.Tests`.
- Run `./scripts/validate.ps1 -SkipDisplay`.
