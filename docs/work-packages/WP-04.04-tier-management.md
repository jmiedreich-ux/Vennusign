# WP-04.04 — Tier Management

## Status

Complete pending authoritative CI, review, and merge.

## Goal

Allow authorized Super Admin operators to manage the subscription-tier lifecycle without deleting historical tier records.

## Scope

- List, create, edit, clone, and archive tiers.
- Validate and normalize commercial tier fields.
- Preserve Stripe catalog mappings during edits.
- Create clones as private and inactive without Stripe mappings.
- Add a responsive tier editor and lifecycle actions.
- Add focused non-integration unit tests.

## Acceptance Criteria

1. Tier names and slugs are required and slugs are normalized.
2. Price is non-negative; screen limits are positive or unlimited (`-1`).
3. Clone creates a private inactive copy with a unique slug and no Stripe identifiers.
4. Archive marks a tier inactive without deleting it.
5. Protected API and admin UI support the complete bounded lifecycle.
6. Required non-integration checks pass; integration-type tests are skipped.

## Boundaries

Feature-matrix editing, venue tier switching, Stripe API calls, and destructive deletion are deferred.
