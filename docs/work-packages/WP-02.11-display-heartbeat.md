# WP-02.11 — Display Heartbeat

## Objective

Keep active screens online through a resilient display heartbeat loop.

## In Scope

- Call `POST /api/display/{screenId}/heartbeat` every 30 seconds.
- Send an initial heartbeat after successful boot.
- Stop timers during component teardown.
- Handle temporary failures without creating duplicate loops.
- Add tests using controlled timers.

## Out of Scope

- Server-side offline detection
- SignalR event handling
- Changes to the heartbeat API contract unless a verified defect requires it

## Acceptance Criteria

- A single heartbeat loop runs per active display.
- Heartbeats update the existing backend `LastSeen` and online status behavior.
- Temporary failures are handled without crashing the display.
- Navigation or teardown stops the loop.

## Required Validation

- Display timer tests and build
- Existing heartbeat API tests
- `./scripts/validate.ps1 -SkipIntegration`

## Dependencies

WP-02.09. WP-02.10 may be completed before or after this package.
