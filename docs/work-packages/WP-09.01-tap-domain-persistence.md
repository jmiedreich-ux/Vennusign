## Goal

Add an honest, venue-scoped tap category and tap item persistence foundation separate from the generic menu domain.

## Acceptance Criteria

- Categories support name, optional category price, active state, and deterministic order.
- Items support category, name, style, ABV, IBU, description, price, glass/name colors, availability, coming-soon state, and deterministic order.
- Composite relationships prevent a tap item from referencing another venue's category.
- Repository reads require venue scope and use stable ordering.
- Migration inventory and focused non-integration unit tests pass.
- Integration-type tests remain skipped.

## Migration

Migration 028 creates `TapCategories` and `TapItems` with venue ownership, bounds, color/range checks, and deterministic ordering indexes.

## Out of Scope

Administration, layouts, pairing changes, POS data, and integration-type tests.
