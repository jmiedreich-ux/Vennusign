## Goal

Add a claim-bound Square connect, callback, status, and disconnect flow while keeping credentials server-side and catalog synchronization out of scope.

## Acceptance Criteria

- Venue Admin authentication supplies the venue scope for connect, status, and disconnect.
- OAuth state is protected, single-use, expires after ten minutes, and carries the correlated venue.
- Square authorization, token, and revoke calls are isolated behind an injectable gateway.
- Provider endpoints are HTTPS and limited to official production or sandbox Square hosts.
- Callback and Venue Admin return destinations are server-configured absolute HTTPS URLs.
- Exchanged tokens persist only through the WP-12.01 credential-protection service and never enter browser responses.
- Disconnect revokes Square access before deleting the venue-scoped connection.
- Focused non-integration tests cover state tampering/replay and connection completion/disconnect ordering.

## Boundaries

No catalog import, webhook, inventory sync, refresh worker, menu mutation, provider credential, or live Square call is included.

## Validation

GitHub Actions is authoritative. Azure SQL, live Square, credentialed, hosted-infrastructure, container, and cross-system integration tests are intentionally skipped.
