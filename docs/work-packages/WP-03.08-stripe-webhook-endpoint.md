# WP-03.08 — Stripe Webhook Endpoint

## Status

Complete. Delivered through PR #27.

## Objective

Expose the existing Phase 03 subscription lifecycle through a verified Stripe webhook transport.

## Scope

- Add `POST /api/webhooks/stripe`.
- Verify the unmodified request body with the configured endpoint signing secret and `Stripe-Signature`.
- Enforce Stripe's five-minute signature timestamp tolerance.
- Map supported Stripe subscription and invoice payloads into `StripeSubscriptionEvent`.
- Dispatch through `IStripeSubscriptionEventHandler`.
- Acknowledge verified unsupported events without processing them.
- Validate webhook configuration at application startup.
- Add focused non-integration unit tests.

## Transport Contract

- `customer.subscription.created` and `customer.subscription.updated` read the venue identifier from subscription metadata key `venue_id`.
- A subscription contains one tier price; the first active subscription item supplies the Stripe price ID and current period end.
- `invoice.paid` reads the subscription ID from `parent.subscription_details.subscription` and the period end from the invoice.
- `customer.subscription.deleted` identifies the local subscription by Stripe subscription ID.

## Acceptance Criteria

- Invalid, missing, malformed, or stale signatures return HTTP 400 without invoking the lifecycle handler.
- Supported events map all fields required by the existing handler.
- Verified unsupported event types return HTTP 200 and do not invoke the handler.
- Duplicate deliveries remain safe through the persistent idempotency service.
- The signing secret and raw payload are not logged or returned.
- Required non-integration GitHub Actions checks pass against the final PR head.
- Integration-type tests are intentionally skipped under the standing repository-owner instruction.

## Scope Boundary

No checkout, customer portal, Stripe API calls, billing UI, HaaS billing, background queue, hosted receiver, or lifecycle/idempotency reimplementation.

## Implemented

- Added the verified `POST /api/webhooks/stripe` transport.
- Added Stripe.net 52.1.0 signature verification with a configurable five-minute default tolerance.
- Added strict subscription and invoice mapping into the existing transport-neutral contract.
- Preserved persistent duplicate protection through `IStripeSubscriptionEventHandler`.
- Added startup validation for the endpoint signing secret and tolerance.
- Added focused tests for valid, invalid, and stale signatures; supported and unsupported events; field mapping; and malformed payloads.
- Added operational configuration guidance.
