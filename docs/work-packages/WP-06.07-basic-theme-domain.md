# WP-06.07 — Basic Theme Domain and Persistence

## Status

In progress.

- Branch: `wp/06.07-basic-theme-domain`
- Issue: #106

## Goal

Create a durable, venue-scoped basic theme contract with safe defaults and validated admin read/update operations.

## Scope

- Persist background color, accent color, font family, and update timestamp per venue.
- Restrict colors to `#RRGGBB` and fonts to Inter, Georgia, or Arial.
- Return deterministic defaults before a venue customizes its theme.
- Add protected venue-scoped GET and PUT endpoints.
- Add focused non-integration tests and migration coverage.

## Acceptance Criteria

1. Theme rows cannot cross venue boundaries and cascade with their venue.
2. Read returns persisted values or deterministic defaults.
3. Update normalizes colors and rejects unsupported values.
4. Required GitHub Actions checks pass.
5. Integration-type tests remain skipped.

## Boundaries

No visual builder, live preview, screen notifications, scheduling, POS, or external integration.
