# WP-04.02 — Venue Directory

## Status

Complete

## Goal

Give internal operations a protected, searchable overview of every venue and its subscription and screen health context.

## Scope

- Aggregate venue, tier, subscription, screen, and active override records.
- Support composable name, tier, subscription-status, and health filters.
- Add a protected directory endpoint and responsive admin table.
- Add focused non-integration tests.

## Acceptance Criteria

1. Directory rows include venue type, tier, subscription status, screen count, last activity, override count, and health.
2. Health is `online`, `degraded`, `offline`, or `no_screens` based on persisted screen status.
3. All filters compose and results are deterministic.
4. The admin UI provides loading, error, empty, search, and filter states.
5. Required non-integration checks pass; integration-type tests are skipped.

## Boundaries

- MRR is deferred until authoritative Stripe revenue semantics are defined.
- Venue detail, tier switching, overrides, and pagination are out of scope.
