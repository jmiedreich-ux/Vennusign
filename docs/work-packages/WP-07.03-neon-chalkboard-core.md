## Goal

Add the first Pro bar layout as a static, TV-safe renderer driven entirely by existing display content and advanced theme values.

## Scope

- Additive `neon_chalkboard` layout key and registry entry.
- Visible `all_layouts` soft lock in screen management.
- Chalkboard surface with neon frame and corner details.
- Two- and three-column menu rendering with current pricing and sold-out state.
- Per-section colour dividers sourced from the advanced theme.
- Focused API normalization, admin, registry, rendering, and style tests.

## Acceptance Criteria

1. Existing layout defaults and fallbacks remain unchanged.
2. Locked venues can see but cannot select Neon Chalkboard.
3. Venue/menu text, item copy, current pricing, and availability come only from display content.
4. Frame, typography, glow, board, and dividers use advanced theme variables.
5. GitHub Actions passes required non-integration checks.
6. Integration-type tests remain skipped.

## Boundaries

No flicker, breathing, draw-in, scanlines, texture animation, Noto assets, Split Layout, scheduling, or later-phase behavior.
