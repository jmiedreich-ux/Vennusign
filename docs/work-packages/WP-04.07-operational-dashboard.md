# WP-04.07 — Operational Dashboard

## Status

Complete pending authoritative CI, review, and merge.

## Goal

Provide the persisted operational portion of the Super Admin dashboard: venue lifecycle counts and an all-screen health map.

## Scope

- Return active, trialing, canceled-last-30-days, and total venue/subscription counts.
- Return online/offline screen totals.
- Return every screen with venue, name, location, status, and last-seen context.
- Add responsive summary cards and a screen-health map.
- Add focused non-integration aggregation tests.

## Acceptance Criteria

1. Counts are derived deterministically from current persisted data.
2. Canceled-last-30-days uses the subscription update timestamp and injected clock.
3. Every screen is represented with assigned venue context or an explicit unassigned label.
4. The admin UI presents responsive metrics and green/red screen health details.
5. Required restore, Release build, admin/display production builds, and unit tests pass.
6. Integration-type tests are skipped under the standing repository-owner exception.

## Boundaries

Stripe-sourced MRR, ARR, average revenue, historical trends, recent commercial events, and tier switching are deferred.
