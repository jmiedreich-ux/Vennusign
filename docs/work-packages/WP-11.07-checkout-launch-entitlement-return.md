## Goal

Connect the Venue Admin upgrade CTA to Stripe-hosted Checkout and handle bounded success/cancel returns while keeping webhook-processed subscription state authoritative.

## Acceptance Criteria

- The upgrade modal creates a checkout session for the selected public tier and monthly/annual interval.
- Only an allowlisted HTTPS `checkout.stripe.com` URL may be launched.
- The CTA has accessible pending/error states and prevents duplicate submissions.
- Exact `checkout=success` and `checkout=cancel` return values produce bounded, dismissible status states.
- Success performs a bounded refresh of the authoritative Venue Admin session, billing presentation, and resolved features.
- Return parameters never mutate tier, capabilities, or entitlements locally.
- Required non-integration Actions checks pass; integration tests remain skipped.

## Boundaries

No Billing Portal, HaaS contract billing, webhook mutation, custom card collection, optimistic feature unlocking, or live Stripe test.
