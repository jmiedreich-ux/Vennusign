# WP-05.06 — Quick Update Mode

## Status

In progress.

- Branch: `wp/05.06-quick-update-mode`
- Issue: #71
- Pull request: Pending

## Goal

Add the mobile-first daily-special and one-scroll item availability journey, including automatic restoration at the next venue-local midnight.

## Scope

- Gate Quick Update with the effective `quick_update` feature.
- Persist one daily-special message per menu.
- Mark unavailable items with a venue-local midnight reset timestamp.
- Restore expired temporary unavailability through a bounded background service.
- Publish successful changes through the existing notification abstraction.
- Add focused non-integration service, worker, migration, and frontend tests.

## Acceptance Criteria

1. Effective feature resolution controls Quick Update access.
2. Venue, menu, section, and item ownership is validated for every mutation.
3. Quick-unavailable items restore at the next venue-local midnight.
4. Daily-special and availability changes notify venue screens.
5. The UI presents one large, single-scroll mobile journey.
6. Required GitHub Actions checks pass on the reviewed head.
7. Integration-type tests remain skipped.

## Boundaries

No general scheduling engine, display templates, screen management, POS integration, pairing, or translation automation.

## Dependencies

- WP-05.05 — Tier-Aware Venue Admin Patterns
- Existing feature-resolution and notification abstractions
