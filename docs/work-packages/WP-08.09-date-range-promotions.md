## Goal

Add venue-local, inclusive date-range promotions that can select display content and layout with deterministic precedence and automatic activation or expiry.

## Acceptance Criteria

- Promotions are venue scoped with inclusive local start/end dates, enabled state, and bounded content.
- Overlapping promotions resolve by priority, most recent start date, creation time, and identifier.
- Protected administration supports list, create, edit, archive, tier-visible preview, and range validation.
- The display payload exposes the active promotion, applies its target layout, and renders optional promotional content.
- A 60-second evaluator emits only effective promotion transitions and the player reloads authoritative content.
- Emergency broadcasts continue to preempt promoted layouts and content.
- Migration inventory, Release build, frontend builds/tests, and non-integration unit tests pass.
- Integration-type tests remain skipped under the standing owner instruction.
