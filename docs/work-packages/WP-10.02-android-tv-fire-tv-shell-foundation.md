# WP-10.02 — Android TV and Fire TV Shell Foundation

## Status

In Review

## Goal

Add a thin Android-family TV shell that launches the authoritative hosted player safely and predictably with a remote control.

## Acceptance Criteria

- The app declares an exported Leanback launcher, requires TV capability, and does not require touch.
- The WebView permits JavaScript and DOM storage while restricting player navigation to the configured HTTPS origin.
- Platform and app-version metadata are injected at document start through the WP-10.01 contract.
- Loading, successful page commit, main-frame failure, and retry states are deterministic.
- The retry action and loaded player receive explicit D-pad focus.
- The shell contains no signing keys, store credentials, durable claimed-screen state, kiosk behavior, or distribution variants.
- Focused non-integration tests cover the manifest, network policy, bridge, focus, and failure boundaries.

## Boundaries

Durable pairing/display state belongs to WP-10.03; boot/lifecycle recovery, kiosk, Fire build variants, store assets, and signing belong to later Phase 10 packages.

## Validation

GitHub Actions is authoritative. Integration-type tests are intentionally skipped.
