# WP-10.08 — LG webOS Package

## Status

Review

## Goal

Add a credential-free LG webOS web package that launches the authoritative hosted player and shared pairing journey.

## Acceptance Criteria

- The webOS manifest declares a bounded TV web application with deterministic resolution, history, icon, and entry-point metadata.
- The launcher starts `/pair` with sanitized `webos` platform and app-version metadata.
- The shared player accepts the approved platform query value while preserving browser fallback.
- Remote Back exits, relaunch resumes deterministically, and foreground restoration is bounded.
- Credential-free build and static validation scripts exist, and GitHub Actions runs static validation.
- Developer-mode credentials, signing material, store credentials, IPK output, proprietary SDKs, and player forks remain excluded.

## Boundaries

No LG enrollment, signing, store submission, simulator install, certification, or physical-device testing.

## Validation

GitHub Actions is authoritative. Integration-type and external simulator/device tests are intentionally skipped.
