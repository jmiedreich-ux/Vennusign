## Goal

## Acceptance Criteria

- Ordered taps render with stable tap numbers and deterministic hand-lettered font rotation.
- Each strip shows name, style, ABV, price, supported name-color glow, and availability/coming-soon state.
- The layout is TV safe and remains on the shared realtime/offline content path.
- Focused API, migration, registry, and display non-integration tests pass.

## Validation
