## Goal

Add separate Hardware-as-a-Service contract billing metadata, fixed-term Checkout guardrails, and deterministic early-cancel disclosure while keeping provider-confirmed events authoritative.

## Acceptance Criteria

- HaaS contracts remain separate from the venue software subscription and record bundle, fixed term, monthly amount, provider subscription, status, and confirmed lifecycle dates.
- Only Starter Kit/18-month, Bar Pack/24-month, and Full House/36-month requests are accepted.
- HaaS Checkout accepts no browser venue or Stripe identifier, returns only an allowlisted hosted URL, and does not activate a contract.
- Confirmed, idempotent Stripe subscription events activate, update, or end the HaaS contract.
- Venue Admin exposes remaining months and a deterministic non-negative remaining-term buyout disclosure.
- No automatic buyout collection occurs; a canceled contract changes only after a confirmed provider event.
- Migration and focused API, data, mapper, and Venue Admin tests are included.
- Required non-integration Actions checks pass; integration/live Stripe tests remain skipped.

## Boundaries

No custom payment UI, hardware fulfillment, automatic buyout invoice or charge, POS behavior, entitlement mutation, or live Stripe test.
