# WP-11.06 — Stripe Checkout Session Foundation

## Status

Complete

## Goal

Add a protected, venue-scoped foundation for creating Stripe-hosted subscription Checkout sessions without exposing provider secrets or changing entitlements optimistically.

## Acceptance Criteria

- Venue Admin authentication supplies the venue scope; the browser cannot select another venue.
- Only active public tiers with a configured monthly or annual Stripe price can be requested.
- Checkout creation is isolated behind an injectable gateway.
- Redirect destinations are server-configured HTTPS URLs.
- The API returns only an allowlisted `checkout.stripe.com` hosted URL.
- No entitlement or subscription state is changed by session creation.
- Focused non-integration tests cover price selection, invalid catalog state, missing venue subscription, and authentication.

## Boundaries

No frontend launch/return flow, Billing Portal, contract billing, webhook mutation, or live Stripe request is included.

## Validation

GitHub Actions is authoritative. Stripe network, Azure SQL, credentialed, hosted-infrastructure, and other integration-type tests are intentionally skipped.
