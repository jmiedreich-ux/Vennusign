# WP-04.01 — Super Admin CRM Foundation

## Status

Complete

## Goal

Establish the protected API and independent web application foundation used by the Phase 04 internal Super Admin CRM.

## Scope

- Add a configurable API-key authentication scheme and `SuperAdmin` authorization policy.
- Add a protected `/api/admin/session` endpoint for client bootstrap.
- Add an independent React/Vite admin application with Dashboard, Venues, Tiers, and Features routes.
- Extend CI to build the admin application.

## Acceptance Criteria

1. Requests to Super Admin APIs without a valid configured key receive `401`.
2. Valid requests can bootstrap a Super Admin session without exposing the configured key.
3. The admin application has explicit API/key configuration, protected bootstrap behavior, navigation, and clear loading/unauthorized states.
4. Restore, Release build, admin production build, display production build, and unit tests pass in GitHub Actions.
5. Integration-type tests remain skipped under the standing owner exception.

## Architecture Boundaries

- Admin HTTP transport and authorization remain in `Vennu.Api`.
- The Super Admin SPA is isolated under `src/admin` and is not added as a Visual Studio Website project.
- Authentication secrets are supplied through configuration and are never committed.

## Validation

- `npm ci && npm run build` in `src/admin`
- Existing display build
- .NET Release build and unit tests in GitHub Actions
- Integration-type tests intentionally skipped
