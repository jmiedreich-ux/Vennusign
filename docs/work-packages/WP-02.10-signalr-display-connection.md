# WP-02.10 — SignalR Display Connection

## Objective

Connect the display client to VennuHub and process real-time screen updates.

## In Scope

- Connect to `/hubs/vennu`.
- Call `JoinScreen(screenId)` after connection.
- Add automatic reconnect behavior.
- Handle `ContentUpdated`, `ThemeUpdated`, `ItemAvailabilityChanged`, and `SyncTick` using existing payload contracts.
- Update local display state without a full page reload.
- Add focused client tests.

## Out of Scope

- Heartbeat scheduling
- Backend notification abstraction
- New real-time event names or payload redesign

## Acceptance Criteria

- The client joins the correct screen group.
- Reconnection restores group membership.
- Each supported event has a deterministic handler.
- Connection failures show a controlled degraded state.

## Required Validation

- Display tests and build
- SignalR-related backend tests
- `./scripts/validate.ps1 -SkipIntegration`

## Dependencies

WP-02.09.
