# WP-02.14 — Phase 02 Vertical-Slice Validation

## Objective

Prove the Phase 02 milestone end to end before Phase 03 begins.

## In Scope

- Run the complete automated validation suite.
- Validate with separate admin/API and display client contexts.
- Create a venue and screen.
- Create and claim a pairing code.
- Load display content.
- Confirm SignalR group connection and a real-time update.
- Confirm heartbeat updates `LastSeen` and online status.
- Stop heartbeats and confirm the screen becomes offline after the configured threshold.
- Record evidence and any accepted limitations.

## Acceptance Criteria

- Display content loads for a paired screen.
- A pushed update reaches the correct display without reloading.
- Heartbeats maintain online status.
- Missing heartbeats produce offline status.
- All required tests and builds pass.
- `PROJECT_STATUS.md` marks Phase 02 complete and identifies the first Phase 03 package.

## Required Validation

- `./scripts/validate.ps1`
- Documented two-context manual validation

## Dependencies

WP-02.08 through WP-02.13.

## Phase Gate

Phase 03 must not begin until this package is complete.
