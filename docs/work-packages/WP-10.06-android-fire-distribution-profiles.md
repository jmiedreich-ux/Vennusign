# WP-10.06 — Android and Fire Distribution Profiles

## Status

Complete

## Goal

Add reproducible unsigned Google TV and Amazon Fire TV profiles with centralized release inputs and CI validation.

## Acceptance Criteria

- Google TV and Fire TV flavors use distinct application IDs and platform identities.
- Version code, version name, and hosted-player URL have safe defaults and documented environment/Gradle overrides.
- Channel metadata and a release-operator checklist cover both stores.
- GitHub Actions assembles both unsigned debug variants.
- APKs, app bundles, keystores, passwords, store credentials, and release signing remain excluded.
- Focused non-integration tests validate profiles, metadata, CI commands, and secret boundaries.

## Boundaries

No store enrollment, signing, upload, submission, certification, production release, or physical-device testing.

## Validation

GitHub Actions is authoritative. Integration-type and physical-device tests are intentionally skipped.
