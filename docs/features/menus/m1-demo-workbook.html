Start here

Two commands. The first starts the product; the second walks every check and prints what each one actually returned. You read the output and record your judgment below — you do not have to call any endpoint by hand.

  1. Open PowerShell in C:\Development\VennuSign, on the feature/menus-m1-spine branch. Start the product (migration 058 applies automatically):
powershell -ExecutionPolicy Bypass -File scripts/start-ui-test-env.ps1
  1. Wait for the API to answer on https://localhost:7138. If it never comes up, that is a Fail on check 1 — capture the output of artifacts/ui-test-env/api.out.log.
  2. Run the demo. It finds a menu, an item and a screen for you, assigns the menu to that screen so the screen-facing checks mean something, walks the checks in order, making real edits through the editor so the derived draft has something to compute, and puts the data back afterwards:
powershell -ExecutionPolicy Bypass -File scripts/run-m1-demo.ps1
  1. Read each result against the check below and record Pass, Fail or Needs Adjustment. The script says what it saw; you decide whether that is right.
  2. Add -Json artifacts/m1-demo-evidence.json to keep a machine-readable record alongside your workbook export.

Every timestamp is rendered in the venue’s local time, not your own — deliberate, and check 1 verifies it. Each check below also lists the raw call, if you would rather drive it yourself.
