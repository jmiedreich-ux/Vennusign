Start here: run the API against a database with migration 058 applied

  1. Open PowerShell in C:\Development\VennuSign.
  2. Start the local environment. Migration 058_create_menu_item_library_spine.sql applies automatically on API startup:
powershell -ExecutionPolicy Bypass -File scripts/start-ui-test-env.ps1
  1. Wait until the API answers on https://localhost:7138. If it never comes up, the migration failed — that is itself a Fail on check 1.
  2. Sign in to the Back Office at https://localhost:5174 so your browser holds a back-office session; every endpoint below is authenticated and venue-scoped.
  3. Call the endpoints from your browser devtools console, or any REST client that sends that session. Replace {menuId} and {itemId} with ids from the seeded venue.

Every timestamp you see is rendered in the venue’s local time, not your own — that is deliberate, and check 1 verifies it.
