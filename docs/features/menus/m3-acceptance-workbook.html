Start here

One command, then you look at it. Milestone 1 had no screens, so it was accepted by reading an API. This one has screens, so it is accepted by using them — every check below is something you can see.

  1. Open PowerShell in C:\Development\VennuSign, on the feature/menus-m2-shell-render branch. Start the product (migrations 059 and 060 apply automatically):
powershell -ExecutionPolicy Bypass -File scripts/start-ui-test-env.ps1
  1. Wait for the Back Office to answer on https://localhost:5174. If it never comes up, that is a Fail on check 1 — capture artifacts/ui-test-env/api.out.log.
  2. Sign in with the owner link below, then open Menu in the icon rail. That is Menus home — the shelf.
  3. Walk the checks in order. Record Pass, Fail or Needs Adjustment for each. Where a check says something should be absent, absent is the point: look for it and confirm it is not there.
  4. Export the JSON record when you are done; it is the acceptance evidence.
