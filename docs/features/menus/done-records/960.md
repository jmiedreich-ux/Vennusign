## Design questions

- **Should Fish (a 1-item page) be automatically merged into a neighboring page so it doesn't sit alone on a mostly-black screen?** Discussed directly with the owner and deliberately deferred, not built. A page is something an operator named and separated in Back Office on purpose; silently combining pages changes their menu structure without asking, and what merges with what could shift unpredictably if they later reorder or rename pages. If wanted, this belongs either as an explicit opt-in setting or as a Back Office nudge that lets the operator decide - not automatic display-side behavior.
- **Does a virtual sub-page need its own visual indicator ("2 of 3")?** Not built. Sections keep their own headers as they rotate, which already tells a viewer content continued rather than changed topic; a page counter was judged unnecessary for a first pass and can be added later if it's missed.
- **Does dwell time need to differ for a sub-page vs. a real page** (less content, arguably less time needed)? Not built - reuses the same `PageDwellSeconds` as real pages. Flagged as a tuning question for after live viewing, not a correctness question.

All other template questions (edit, delete, drag-and-drop, talking to another function) are N/A - this is a rendering-time computation with no new user-facing screen or interaction.
