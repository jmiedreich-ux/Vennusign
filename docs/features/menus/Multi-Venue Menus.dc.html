Multi-venue menus

Twelve bars under one brand, corporate authoring the core menus, operators running the floor. The single-venue wireframes don't break here — they get one extra dimension. The rule that governs it: a menu is one object, and each venue's relationship to it is a state on that object, not a copy of it. That's why the default view is the same shelf of menus a single venue sees, with the group answer on each card — not a grid of venues each holding their own menus.
