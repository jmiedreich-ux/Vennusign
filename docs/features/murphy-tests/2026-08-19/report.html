"Continue with Google" leads to a bare 503 JSON page — Google isn't configured on dev

One of the redesigned landing page's only two sign‑in options is a dead end for every dev visitor who clicks it.

Repro: open https://dev.back-office.vennusign.com/signup, click Continue with Google.

Seen on: dev, master@de2472a5

Expected: either the provider works, or the app catches the failure and shows an in‑app "try another way to sign in" state.

Actual: full‑page navigation to vennusign-dev-api.azurewebsites.net/api/customer-auth/external/google, which returns raw 503 {"detail":"The requested identity provider is not configured."} — no app chrome, no way back except browser Back.

Compounds with the "remembered method" feature: a browser that last used Google shows only the broken button by default, with the working "Continue with Vennusign" option hidden behind a secondary "More ways to sign in" click.
